# MedoEDUz Sync Worker

Cloudflare Worker для синхронизации прогресса обучения по Telegram user_id.

- `index.js` — сам воркер: валидация Telegram initData (HMAC-SHA256) +
  KV-хранилище прогресса + слияние состояний.
- `wrangler.toml` — конфигурация (нужно вставить KV namespace id).

**Полная инструкция по развёртыванию:** `../docs/telegram-setup.md`, часть 2.

## Эндпоинты

Все требуют заголовок `X-Telegram-Init-Data` с подписанной строкой.

| Метод | Путь | Действие |
|-------|------|----------|
| GET | `/v1/progress` | вернуть прогресс пользователя |
| PUT | `/v1/progress` | заменить целиком (клиент новее) |
| PATCH | `/v1/progress` | слить с серверным (по узлам) |
| DELETE | `/v1/progress` | удалить свой прогресс |

## Безопасность

user_id извлекается ТОЛЬКО из проверенной подписи, не из тела запроса.
Подделка невозможна без bot-токена, который лежит в секретах Cloudflare.
Логика валидации протестирована (см. тест в истории коммитов): валидная
подпись проходит, подделка/подмена/просрочка/пустое — отклоняются.
