# Руководство по внесению вклада в MedoEDUz

Спасибо за интерес к проекту MedoEDUz! Мы рады любому вкладу в развитие платформы.

## 🚀 Как начать

1. **Fork репозитория**
   ```bash
   # Склонируйте ваш fork
   git clone https://github.com/YOUR_USERNAME/MedoEDUz.git
   cd MedoEDUz
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Создайте ветку для вашей функции**
   ```bash
   git checkout -b feature/amazing-feature
   ```

## 📝 Процесс разработки

### Требования к коду

1. **HTML**
   - Используйте семантические теги
   - Добавляйте alt-текст для изображений
   - Соблюдайте accessibility стандарты

2. **CSS**
   - Используйте CSS переменные для цветов
   - Следуйте mobile-first подходу
   - Проверяйте код линтером: `npm run lint:css`

3. **JavaScript**
   - Пишите на современном ES6+
   - Используйте const/let вместо var
   - Проверяйте код линтером: `npm run lint:js`

### Стиль кода

Мы используем Prettier для форматирования кода:

```bash
npm run format
```

### Тестирование

Перед отправкой PR убедитесь, что:

- [ ] HTML валидируется: `npm run validate`
- [ ] CSS линтер проходит: `npm run lint:css`
- [ ] JS линтер проходит: `npm run lint:js`
- [ ] Сайт корректно работает на мобильных устройствах
- [ ] Нет ошибок в консоли браузера

## 🔄 Процесс Pull Request

1. **Обновите свою ветку**
   ```bash
   git fetch upstream
   git rebase upstream/main
   ```

2. **Коммитьте изменения**
   ```bash
   git add .
   git commit -m "feat: добавлена новая функция"
   ```

   Используйте [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` новая функция
   - `fix:` исправление бага
   - `docs:` изменения в документации
   - `style:` форматирование кода
   - `refactor:` рефакторинг
   - `test:` добавление тестов
   - `chore:` обновление зависимостей

3. **Отправьте изменения**
   ```bash
   git push origin feature/amazing-feature
   ```

4. **Создайте Pull Request**
   - Опишите что изменилось
   - Добавьте скриншоты (если это UI изменения)
   - Упомяните связанные issues

## 🐛 Сообщения об ошибках

Если вы нашли баг, создайте issue с:

- Описанием проблемы
- Шагами для воспроизведения
- Ожидаемым поведением
- Скриншотами (если применимо)
- Информацией о браузере/ОС

## 💡 Предложения
