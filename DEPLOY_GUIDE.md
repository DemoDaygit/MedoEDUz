# 🚀 РУКОВОДСТВО ПО РАЗВЕРТЫВАНИЮ (ДЕПЛОЮ)

Этот лендинг — статический сайт, что означает, что он состоит только из HTML, CSS и JavaScript. Его можно разместить практически где угодно.

## 1. Рекомендуемый способ: GitHub Pages (Бесплатно)

Это самый простой и быстрый способ запустить сайт, если ваш код уже на GitHub.

### Шаги:

1.  **Убедитесь, что код на ветке `main`:**
    *   Все последние изменения (включая этот честный манифест) уже находятся в ветке `main` вашего репозитория `DemoDaygit/MedoEDUz`.

2.  **Перейдите в настройки Pages:**
    *   Откройте репозиторий на GitHub.
    *   Перейдите во вкладку **Settings** (Настройки).
    *   В левом меню выберите **Pages** (Страницы).

3.  **Настройте источник:**
    *   В разделе **"Source"** (Источник) или **"Сборка и развертывание"** (Build and deployment) выберите:
        *   **Source:** `Deploy from a branch` (Развертывание из ветви).
        *   **Branch:** Выберите ветку **`main`**.
        *   **Folder:** Выберите **`/ (root)`** (корень).

4.  **Сохраните и ждите:**
    *   Нажмите кнопку **Save** (Сохранить).
    *   GitHub начнет сборку. Через 1-5 минут ваш сайт будет доступен по адресу, который отобразится на этой же странице (например, `https://demodaygit.github.io/MedoEDUz/`).

## 2. Альтернативные способы

| Платформа | Плюсы | Минусы |
| :--- | :--- | :--- |
| **Vercel** | Очень быстрая настройка, автоматический HTTPS, отличная производительность. | Требует регистрации, может быть избыточен для простого лендинга. |
| **Netlify** | Похож на Vercel, простая интеграция с GitHub. | Аналогично Vercel. |
| **Обычный хостинг** | Полный контроль. | Требует ручной загрузки файлов (FTP/SFTP). |

## 3. Чеклист перед запуском

*   ✅ **Ветка:** Убедитесь, что вы развертываете ветку `main`.
*   ✅ **Ссылки:** Проверьте все ссылки на Telegram в футере и кнопках.
*   ✅ **Адаптивность:** Проверьте, как сайт выглядит на вашем телефоне.
*   ✅ **Честность:** Убедитесь, что вы готовы к честному диалогу с аудиторией.
