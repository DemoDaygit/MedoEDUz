# 🎮 MedoEDUz Game Engine — Игровой движок UI/UX

Документация по системе геймификации, эволюции интерфейса и анимационному движку.

## Концепция

Пользователь — это **«Медоед»**, который растёт и эволюционирует по мере
изучения экосистемы. Каждое осмысленное действие приносит **опыт (XP)**,
повышает **уровень**, открывает **достижения** и запускает **стадии эволюции**.
Сам интерфейс визуально «взрослеет» вместе с игроком: чем выше стадия —
тем богаче анимации, свечения и эффекты.

Прогресс хранится в `localStorage` и **синхронизируется между всеми
страницами** проекта — путешествие по сайту воспринимается как единая игра.

## Архитектура

Движок разбит на 4 независимых модуля + 2 файла стилей:

| Файл | Назначение |
|------|-----------|
| `js/gamification.js` | Ядро: состояние, XP, уровни, эволюция, достижения, персистентность |
| `js/animations.js` | Анимационный движок: частицы, курсор, 3D-tilt, reveal, конфетти, счётчики |
| `js/game-ui.js` | Визуальный слой: HUD-аватар, панель профиля, церемонии, тосты |
| `js/game-integration.js` | Связующий слой: привязка игровых событий к действиям на сайте |
| `css/animations.css` | Стили эффектов и тематизация интерфейса по стадиям эволюции |
| `css/game-ui.css` | Стили HUD, панели, церемоний левел-апа и эволюции |

Модули общаются через простую событийную шину `GameEngine.on(event, fn)`.
События: `ready`, `xp`, `levelup`, `evolve`, `achievement`.

## Стадии эволюции

| Ур. | Стадия | Маскот | Эффекты интерфейса |
|-----|--------|--------|--------------------|
| 1 | Медвежонок | 🐻 | базовый вид |
| 3 | Любопытный | 🧸 | свечение кнопок |
| 6 | Ученик ИИ | 🤖 | пульсация бейджа |
| 10 | Нейро-Мастер | 🦾 | анимированные градиенты заголовков |
| 15 | Гуру ИИ | 🧠 | плавающие карточки |
| 20 | Медоед ВСЁ | 👑 | «аврора» на фоне hero |

Стадия применяется через атрибут `html[data-evolution="N"]`, который читается
из CSS — поэтому добавлять новые визуальные эффекты можно чисто декларативно.

## Как зарабатывается XP

| Действие | Награда |
|----------|---------|
| Посещение секции (впервые) | +15 XP |
| Изучение курса (клик/долгое наведение) | +25 XP |
| Активность (клики, не чаще раза в 3 c) | +5 XP |
| Разблокировка достижения | от +50 до +500 XP |

Требование XP к уровню растёт экспоненциально (`base 100 × 1.35^(n-1)`).

## Достижения

11 ачивок: первый шаг, исследователь (все секции), любознательный (3 курса),
книжный червь (доскролл), социальный, решительный (форма), полуночник,
серия из 3 дней, 5-й уровень, первая эволюция и секретный **Konami-код**
(↑↑↓↓←→←→ B A).

## Производительность и доступность

- Все эффекты **уважают `prefers-reduced-motion`** и отключаются при запросе.
- На мобильных устройствах число частиц снижается, тяжёлые эффекты
  (курсор, 3D-tilt, магнитные кнопки) отключаются.
- Анимации используют `transform`/`opacity` и `will-change` для работы на GPU.
- Canvas-эффекты (частицы, конфетти) самоочищаются и не текут по памяти.

## Отладка

```js
GameEngine.getState();        // текущее состояние игрока
GameEngine.addXP(500, 'test'); // выдать опыт вручную
GameEngine.unlock('explorer'); // разблокировать достижение
GameEngine.reset();            // полный сброс прогресса
```

## Расширение

- **Новая стадия эволюции** — добавьте объект в `EVOLUTION_STAGES`
  (`gamification.js`) и при желании стили `html[data-evolution='N']`.
- **Новое достижение** — добавьте объект в `ACHIEVEMENTS` и вызовите
  `GameEngine.unlock('id')` в нужном месте `game-integration.js`.
- **Новый анимационный эффект** — добавьте метод в `AnimationEngine`
  и вызовите его из `init()`.
