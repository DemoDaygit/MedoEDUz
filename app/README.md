# 🐻 MedoEDUz — Автономная игровая экосистема (PWA)

Самодостаточное приложение, демонстрирующее базовые визуальные механики
игровой экосистемы MedoEDUz: фоновые частицы-«нейросеть», система XP и
уровней, **эволюция маскота**, мини-дерево навыков и церемонии (левел-ап,
эволюция, конфетти). Работает **полностью офлайн** и ставится как приложение
на **Android и iOS**.

## ⚡ Что внутри

| Файл | Назначение |
|------|-----------|
| `learn.html` | **Учебная сессия** — экран, где идёт собственно обучение |
| `learn.css` / `learn.js` | Стили и логика учебной сессии |
| `refs.js` | Ссылки на открытые первоисточники (Kaggle, Google, OWASP и др.) |
| `index.html` | Граф знаний и эволюция маскота |
| `data/curriculum.js` | Модель курса — копия `js/data/curriculum.js` (её обновляет `build-app.sh`) |
| `config.js` | Единая точка настройки синхронизации |
| `manifest.webmanifest` | Манифест PWA (имя, иконка, режим standalone) |
| `sw.js` | Service worker — офлайн-кэш оболочки |
| `icon.svg` | Иконка приложения |

Никаких внешних зависимостей и CDN — приложение автономно. Telegram SDK
подключается опционально и с `async`: не загрузился — всё работает как
обычный сайт.

## 🎯 Два экрана

- **`learn.html` — учебная сессия.** Замкнутый цикл: план → повторение →
  изучение → практика → проверка с оценкой уверенности → рефлексия.
  Плюс дневник (калибровка, пробелы, намерения), путь по трекам и профиль
  с диагностикой. Это и есть то, что стоит открывать как Telegram Mini App.
- **`index.html` — карта и эволюция.** Граф знаний с «туманом войны»,
  XP, уровни, стадии маскота. Прогресс у экранов общий: они пишут в один
  ключ `localStorage`.

## 🚀 Быстрый запуск (без установки)

Просто откройте `index.html` в браузере — на компьютере или телефоне.
Прогресс сохраняется на устройстве, интернет не нужен.

> На `file://` работает всё, кроме service worker (это ограничение браузеров).
> Для офлайн-кэша и установки как приложения откройте через локальный сервер
> или хостинг (см. ниже).

## 📲 Установка как приложение

### Android (Chrome)
1. Откройте адрес приложения в Chrome.
2. Появится подсказка **«Установить приложение»** — нажмите её.
   (или меню ⋮ → «Установить приложение» / «Добавить на главный экран»).
3. Иконка MedoEDUz появится на рабочем столе, запуск — в полноэкранном режиме.

### iOS (Safari)
1. Откройте адрес приложения в **Safari** (важно: именно Safari).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой).
3. Выберите **«На экран „Домой“»** → «Добавить».
4. Приложение запустится в отдельном окне без панелей браузера.

## 🌐 Как раздать по сети (для теста на телефоне)

Из папки `app/` запустите любой статический сервер:

```bash
# Python
python -m http.server 8080

# или Node
npx serve .
```

Затем на телефоне (в той же Wi-Fi-сети) откройте
`http://АДРЕС-КОМПЬЮТЕРА:8080`. Чтобы заработали установка и офлайн-кэш на
iOS/Android, нужен **HTTPS** (например, бесплатный хостинг GitHub Pages,
Netlify, Vercel или туннель `ngrok`).

## 🎮 Механики

- **Кнопка «Изучать»** — тап даёт XP (иногда крит ×5 с особым эффектом),
  с тактильной отдачей (вибрация на Android).
- **XP и уровни** — экспоненциальный рост требований.
- **Эволюция** — на уровнях 3/5/8/11/14 маскот превращается
  (🐻→🧸→🤖→🦾→🧠→👑), меняется аура и цвет частиц.
- **Дерево навыков** — узлы открываются по достижении нужного уровня;
  тап по доступному навыку осваивает его и даёт XP.
- **Церемонии** — анимации левел-апа, эволюции и конфетти.

## 📦 Упаковка в нативный пакет (опционально)

PWA можно превратить в настоящий установочный пакет магазинов:

- **PWABuilder** (`https://www.pawbuilder.com`/`pwabuilder.com`) — загрузите
  URL развёрнутой PWA и получите готовый **Android (.aab/.apk)** и пакет для
  **iOS** (через обёртку), готовые к публикации.
- **Capacitor** — обернуть в нативный проект:
  ```bash
  npm i @capacitor/core @capacitor/cli
  npx cap init MedoEDUz com.medoeduz.app --web-dir .
  npx cap add android   # и/или: npx cap add ios
  npx cap open android   # сборка APK в Android Studio
  npx cap open ios       # сборка IPA в Xcode (нужен Mac)
  ```

> Честно: финальная сборка `.apk`/`.ipa` и публикация требуют Android Studio /
> Xcode и подписи разработчика — это делается на машине разработчика, а не
> «скачиванием файла». PWA выше работает на обеих платформах уже сейчас.
