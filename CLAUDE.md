# MedoEDUz - Документация для Claude

## О проекте

**MedoEDUz** ("Медоеду ВСЁ") - образовательная платформа для обучения навыкам работы с современными ИИ-инструментами.

## Архитектура проекта

### Структура файлов

```
MedoEDUz/
├── index.html              # Главная страница (Landing Page)
├── css/
│   └── style.css          # Все стили проекта
├── js/
│   └── script.js          # JavaScript функциональность
├── images/                # Изображения и медиа
├── pages/                 # Дополнительные страницы (курсы, FAQ)
├── api/                   # API endpoints (будущая разработка)
└── config/                # Конфигурационные файлы
```

### Технологический стек

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Стили**: CSS Grid, Flexbox, CSS Variables
- **Шрифты**: Google Fonts (Inter)
- **Иконки**: Emoji (нативные)
- **Анимации**: CSS Transitions, Intersection Observer API

## Ключевые компоненты

### 1. HTML структура (index.html)

Одностраничное приложение со следующими секциями:
- **Навигация**: Фиксированная, адаптивная
- **Hero секция**: Главный экран с CTA
- **О проекте**: Миссия, подход, цели
- **Преимущества**: 6 карточек преимуществ
- **Курсы**: 6 направлений обучения
- **Отзывы**: Карточки отзывов студентов
- **Контакты**: Форма обратной связи
- **Футер**: Навигация и контакты

### 2. CSS (css/style.css)

**CSS переменные** (`:root`):
```css
--primary-color: #6366f1    /* Основной цвет (Индиго) */
--accent-color: #ec4899     /* Акцентный цвет (Розовый) */
--secondary-color: #f59e0b  /* Вторичный цвет (Янтарный) */
```

**Ключевые особенности**:
- Mobile-first подход
- Breakpoints: 640px, 968px
- CSS Grid для layout
- Плавные анимации (0.3s ease)

### 3. JavaScript (js/script.js)

**Основные функции**:
- `initNavbar()` - Инициализация навигации
- `initScrollEffects()` - Эффекты при скролле
- `initForm()` - Обработка формы
- `scrollToSection()` - Плавный скролл
- `showNotification()` - Система уведомлений

**API взаимодействия**:
- Intersection Observer для анимаций
- Form API для валидации
- Local Storage (для будущих функций)

## Важные правила разработки

### ❌ НЕ делать:

1. **НЕ добавлять jQuery или тяжелые фреймворки** - проект на Vanilla JS
2. **НЕ использовать inline стили** - все стили в style.css
3. **НЕ добавлять Bootstrap или Tailwind** - кастомный CSS
4. **НЕ забывать про accessibility** - alt текст, aria-labels
5. **НЕ игнорировать мобильную версию** - mobile-first!

### ✅ Делать:

1. **Использовать CSS переменные** для цветов и размеров
2. **Писать семантичный HTML** (section, article, nav)
3. **Оптимизировать изображения** перед добавлением
4. **Тестировать на разных устройствах** (320px - 1920px)
5. **Валидировать формы** на клиенте и сервере
6. **Документировать сложную логику** в комментариях
